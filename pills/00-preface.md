# 前言

本文是 **Nix Pills** 的移植版本，这是由 **Luca Bruno**（ aka Lethalman）撰写、最初发表于 2014 年和 2015 年的一系列博客文章。它以名为「药丸」（pill）的短篇章节的形式，提供了关于 Nix 软件包管理器和 Nixpkgs 软件包集合的教程式入门介绍。

由于 Nix Pills 被视为 Nix 的经典入门读物，Graham Christensen（ aka grahamc / gchristensen）和其他贡献者于 2017 年发起了将其移植为当前格式的工作。

如需最新版本，请访问 <https://nixos.org/guides/nix-pills/>。另有[EPUB 版本](https://nixos.org/guides/nix-pills/nix-pills.epub)可供下载。

如果遇到问题，请在 [nixos/nix-pills](https://github.com/NixOS/nix-pills/issues) 问题跟踪器上报告。
